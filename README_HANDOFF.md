# Передача реализации

Работающее приложение находится в этом репозитории. См. [README](README.md) для запуска и [docs/VALIDATION.md](docs/VALIDATION.md) для результатов проверки.

Исходные `MVP_SPEC.md`, `CODEX_TASK.md`, `AGENTS.md` сохранены. Последующий запрос добавил FSD frontend и Steam → CS2 → личный дашборд: [docs/STEAM.md](docs/STEAM.md). Изменения не отменяют требования корректного парсинга, nullable метрик и локального хранения.

Для live Steam/автозагрузки нужны настоящие авторизация, Web API key и SteamClient-сессия GC worker. В поставке нет секретов, пользовательской SQLite или `.dem`; установите зависимости и подключите собственные данные локально.
